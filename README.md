# 🛍️ Product Catalog

## 🌟 Описание проекта

Product Catalog - это мощный инструмент управления продуктами и категориями, разработанный с использованием Python. 
Проект предоставляет гибкие возможности для работы с каталогом товаров, включая динамическое добавление, валидацию и логирование операций.

- 📊 Автоматический подсчет продуктов и категорий

- 🆕 Новые методы и возможности
- - 🔐 Абстрактные базовые классы для расширяемости
- 🧩 Поддержка миксинов для расширения функциональности

## 💡 Использование

### Создание продукта
```
    from src.models import Product, Category

    # Создание продукта
    smartphone = Product("iPhone 13", "Смартфон", 80000.0, 10)

    # Создание категории
    electronics = Category("Электроника", "Современные электронные устройства")
    electronics.add_product(smartphone)
```

### Итерация по продуктам в категории
```
    for product in electronics:
    print(product)
```    

### Управление ценами
```
    # Изменение цены с подтверждением
    smartphone.price = 75000.0  # Потребует подтверждения при понижении
```

### Работа с ценами и количеством
```
   # Изменение цены с проверками
   smartphone.price = 85000.0  # Потребует подтверждения при понижении
   
   # Автоматическое обновление существующих продуктов
   existing_products = [smartphone]
   new_smartphone = Product.create_product({
       "name": "iPhone 14",
       "quantity": 5,
       "price": 95000.0
   }, existing_products)
```

### Подсчет и статистика
```
   # Получение общего количества продуктов
   total_products = Category.get_total_product_count()
   print(f"Всего продуктов: {total_products}")
```

### Создание продуктов с различными входными данными

## 📦 Основные классы

### 🏗️ Абстрактные базовые классы

#### BaseContainer
- Базовый абстрактный класс для контейнеров
- Поддерживает подсчет общего количества созданных объектов
- Требует реализации метода `__str__`

#### BaseProduct
- Абстрактный базовый класс для всех продуктов
- Определяет общий интерфейс для работы с продуктами
- Требует реализации методов:
  - `__init__`
  - `__str__`
  - `__add__`
  - `price` (свойство)

#### PrintInfoMixin
- Миксин для расширения функциональности классов
- Добавляет логирование при создании объектов
- Расширяет метод `__repr__`
