# 🛍️ Product Catalog

## 🌟 Описание проекта

Product Catalog - это мощный инструмент управления продуктами и категориями, разработанный с использованием Python. 
Проект предоставляет гибкие возможности для работы с каталогом товаров, включая динамическое добавление, валидацию и логирование операций.

## 🚀 Особенности проекта

- 📦 Управление продуктами и категориями
- 🔄 Динамическое добавление и обновление товаров
- 🛡️ Проверка и валидация данных
- 📝 Расширенное логирование операций
- 💰 Гибкая система ценообразования
- 📊 Автоматический подсчет продуктов и категорий

## 🛠️ Технологический стек

- Python 3.10+
- Poetry (управление зависимостями)
- Pytest (тестирование)
- Logging (расширенное логирование)

## 🔧 Установка

1. Клонируйте репозиторий:
    ```
    git clone https://github.com/ваш-логин/ProductCatalog.git
    cd ProductCatalog
    ```
2. Установите зависимости:
    ```
    pip install poetry
    poetry install
    ```

## 💡 Использование

### Создание продукта
```
    from src.models import Product, Category

    # Создание продукта
    smartphone = Product("iPhone 13", "Смартфон", 80000.0, 10)

    # Создание категории
    electronics = Category("Электроника", "Современные электронные устройства")
    electronics.add_product(smartphone)
   ```
    # Итерация по продуктам в категории
```
    for product in electronics:
    print(product)
```    


### Управление ценами
```
    # Изменение цены с подтверждением
    smartphone.price = 75000.0  # Потребует подтверждения при понижении
   ```

## 🧪 Тестирование
```
   poetry run pytest
```

### Типы тестов

- ✅ Тестирование инициализации продуктов
- ✅ Тестирование создания категорий
- ✅ Проверка добавления продуктов
- ✅ Валидация данных
- ✅ Обработка пограничных случаев

## 📦 Основные классы

### 🏷️ Класс Product

#### Атрибуты
- name: Название продукта
- description: Описание продукта
- price: Цена продукта
- quantity: Количество товара

#### Особенности
- Защищенное изменение цены
- Проверка корректности цены
- Логирование изменений

### 📁 Класс Category

#### Атрибуты
- name: Название категории
- description: Описание категории
- products: Список продуктов

#### Статические методы
- Подсчет общего количества категорий
- Получение общего количества продуктов


## 🔍 Функциональность

### Загрузка данных
- Парсинг JSON-файлов
- Создание объектов из загруженных данных
- Обработка ошибок при загрузке

### Логирование
- Протоколирование всех операций
- Уровни логирования: INFO, DEBUG, ERROR
- Запись в файл с временными метками
