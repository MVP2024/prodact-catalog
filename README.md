## Описание

Каталог Продуктов позволяет пользователям просматривать, добавлять и управлять продуктами. 
Проект разработан с использованием Python и фреймворка Flask.

## Установка

Чтобы установить проект, выполните следующие шаги:

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/ваш-логин/ProductCatalog.git
   ```
2. Перейдите в директорию проекта:
    ```
   cd ProductCatalog
   ```
3. Установите зависимости:
    ```
   pip install -r requirements.txt
   ```

**Тестирование**

Проект использует pytest для тестирования. В директории tests находятся тесты, которые проверяют функциональность приложения.


**Тестирование функций**

В файле test_main.py находятся тесты для функции main, 
которая загружает категории и продукты из JSON-файла и сохраняет информацию о них в новый JSON-файл. 
Тесты проверяют различные сценарии, включая успешную загрузку данных, 
обработку ошибок при отсутствии файла и обработку некорректного JSON.


**Тестирование классов**

В файле test_models.py находятся тесты для классов Category и Product, которые проверяют их функциональность:

- Инициализация продукта: Тест проверяет, что объект Product инициализируется с правильными атрибутами (название, описание, цена и количество).
- Инициализация категории: Тест проверяет, что объект Category инициализируется с правильными атрибутами и что количество категорий увеличивается при создании новой категории.
- Добавление продукта в категорию: Тест проверяет, что продукт может быть добавлен в категорию и что общее количество продуктов обновляется.
- Добавление нескольких категорий: Тест проверяет, что общее количество категорий увеличивается при создании нескольких категорий.
- Добавление нескольких продуктов: Тест проверяет, что несколько продуктов могут быть добавлены в категорию и что общее количество продуктов обновляется.

Для запуска тестов используйте следующую команду:
    ```
    pytest
    ```

## Структура проекта


**Основная функция**
Функция main загружает категории и продукты из JSON-файла и сохраняет информацию о них в новый JSON-файл. 
Она выполняет следующие шаги:

1. Формирует путь к файлу JSON с данными о продуктах.
2. Проверяет существование файла. Если файл не найден, записывает ошибку в журнал.
3. Загружает категории с помощью функции load_categories.
4. Формирует список категорий и продуктов, включая их названия, описания и цены.
5. Сохраняет результат в новый JSON-файл output_categories.json.
6. Выводит сообщение об успешном сохранении данных и возвращает список категорий и продуктов.

**Функция загрузки категорий**
Функция load_categories загружает данные о категориях и продуктах из JSON-файла. 
Она выполняет следующие шаги:

1. Принимает путь к JSON-файлу в качестве параметра.
2. Загружает данные из файла и проверяет, что они являются списком.
3. Создает объекты Category и Product на основе загруженных данных.
4. Обрабатывает ошибки, возникающие при загрузке данных, и записывает их в журнал.
5. Возвращает список объектов категорий или пустой список в случае ошибок.

**Логгер**

Функция setup_logger настраивает логгер для указанного модуля. 
Она выполняет следующие шаги:

1. Принимает имя модуля и имя директории для хранения файлов логов. 
2. Создает директорию для логов, если она не существует. 
3. Настраивает формат логирования, включая временные метки, имя модуля, уровень логирования и сообщение. 
4. Создает логгер и устанавливает уровень логирования на DEBUG. 
5. Создает обработчик для записи логов в файл с указанной кодировкой и режимом. 
6. Добавляет обработчик к логгеру и возвращает настроенный логгер.

Логирование помогает отслеживать выполнение программы и выявлять ошибки.

***Классы***

**Класс Product**

Класс Product представляет продукт и включает следующие атрибуты:

- name: Название продукта.
- description: Описание продукта.
- price: Цена продукта.
- quantity: Количество продукта в наличии.

Класс инициализируется с заданными атрибутами, что позволяет создавать объекты продукта с необходимой информацией.

**Класс Category**

Класс Category представляет категорию продуктов и включает следующие атрибуты:

- name: Название категории.
- description: Описание категории.
- products: Список объектов Product, принадлежащих данной категории.

Класс также содержит статические атрибуты total_categories и total_products, 
которые отслеживают общее количество категорий и продуктов. 
Метод add_product позволяет добавлять продукты в категорию и увеличивать общее количество товаров.

**Скрипт проверки**

Скрипт check.py используется для проверки загрузки категорий из JSON-файла. Он выполняет следующие шаги:

1. Настраивает уровень логирования на DEBUG. 
2. Формирует путь к файлу JSON, содержащему данные о продуктах. 
3. Выводит путь к файлу и текущую рабочую директорию для отладки. 
4. Загружает категории с помощью функции load_categories. 
5. Выводит загруженные категории в консоль.

Этот скрипт полезен для тестирования и отладки процесса загрузки данных.
